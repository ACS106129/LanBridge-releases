# ベータ版の変更履歴

LanBridge ベータ版の変更をここに記録します。正式版は [CHANGELOG.ja.md](../CHANGELOG.ja.md) にあります。

## [1.1.0-beta.4] - 2026-10-01

### 修正

- 新しいバージョンを最大1時間待たず、数分以内に検出します。

## [1.1.0-beta.3] - 2026-10-01

### 修正

- 「今すぐ更新」はすぐ画面を開き、更新内容はその中で読み込みます。
- ゲーム起動時に DMM Game Player が一瞬表示されなくなりました。
- DMM Game Player が起動していないプログラムは対象外になりました。

## [1.1.0-beta.2] - 2026-10-01

### 変更

- ベータの切り替えは更新を案内するだけで、入れるかはあなたが決めます。
- ベータの更新内容をあなたの言語で、含まれる全版とともに表示します。
- 設定とサイト一覧から不要な説明を削りました。
- すべての通信を VPN に送る間はサイト一覧を隠します。
- DMM Game Player が動いていない間は表示ボタンを押せません。
- パッチはゲームのファイルを変えず、再ダウンロードされません。

### 修正

- DMM Game Player が先にファイルを取得する時もゲームが起動します。
- 更新内容の見出しが正しく表示されます。

## [1.1.0-beta.1] - 2026-09-30

### 追加

- インストール済みの DMM ゲームをワンクリックで起動できます。
- 接続後に DMM アカウントのゲームを自動で読み込みます。
- DMM ゲームをデスクトップとスタートメニューに登録してインストールできます。
- DMM に未ログインならブラウザでログインページを開きます。
- 起動一覧に表示する DMM ゲームを選べます。
- 日本語ロケールでなくても DMM ゲームを日本語コードページで起動します。

### 変更

- DMM Game Player は裏で動き、表示したときだけ前に出ます。
- パッチが対応するゲームを自分で見つけます。
- 通信アニメーションが低くなり、横のボタンもそれに揃いました。
- DMM モードは一覧なしで DMM のサイトを VPN に通します。
