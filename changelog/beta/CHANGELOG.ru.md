# Журнал изменений бета-версий

Здесь записаны изменения бета-версий LanBridge; обычные версии описаны в [CHANGELOG.ru.md](../CHANGELOG.ru.md).

## [1.1.0-beta.2] - 2026-10-01

### Изменено

- Включение или выключение беты только предлагает обновление, а решаете вы.
- Заметки беты показываются на вашем языке со всеми версиями обновления.
- В настройках и списке сайтов убраны лишние подсказки.
- Список сайтов скрыт, пока весь трафик идёт через VPN.
- Кнопка показа DMM Game Player неактивна, пока он не запущен.
- Патчи больше не меняют файлы игры, и DMM Game Player не скачивает их заново.

### Исправлено

- Игры DMM запускаются, даже если DMM Game Player сначала скачивает файл.
- Заголовки в заметках к выпуску отображаются как заголовки.

## [1.1.0-beta.1] - 2026-09-30

### Добавлено

- Установленная игра DMM запускается одним щелчком.
- Игры аккаунта DMM загружаются автоматически после подключения.
- Игру DMM можно установить с ярлыками на рабочем столе и в меню «Пуск».
- Если в DMM Game Player не выполнен вход, страница входа открывается в браузере.
- Можно выбрать, какие игры DMM показываются в списке запуска.
- Игры DMM запускаются с японской кодовой страницей даже без японского языка системы.

### Изменено

- DMM Game Player работает в фоне и выходит вперёд, только когда вы его покажете.
- Патчи сами находят свою игру.
- Анимация трафика стала ниже, и боковые кнопки выровнены по ней.
- Режим DMM сам пускает сайты DMM Game Player через VPN без списка.
