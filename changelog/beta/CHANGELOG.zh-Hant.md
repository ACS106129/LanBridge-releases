# Beta 變更記錄

LanBridge Beta 版的變更記錄在這裡；正式版請見 [CHANGELOG.zh-Hant.md](../CHANGELOG.zh-Hant.md)。

## [1.1.0-beta.2] - 2026-10-01

### 變更

- 開啟或關閉 Beta 只會提示更新，由你決定是否安裝。
- Beta 更新說明以你的語言顯示，並列出這次更新包含的每個版本。
- 設定與網站清單移除多餘的說明文字。
- 所有流量送進 VPN 時隱藏網站清單。
- 沒有執行 DMM Game Player 時，顯示按鈕無法使用。
- Patch 不再修改遊戲檔案，DMM Game Player 不會再重新下載。

### 修正

- DMM Game Player 需要先下載檔案時，DMM 遊戲也能正常啟動。
- 更新說明中的標題正確顯示。

## [1.1.0-beta.1] - 2026-09-30

### 新增

- 已安裝的 DMM 遊戲可一鍵啟動。
- 連線後自動載入 DMM 帳號中的遊戲。
- 可安裝 DMM 遊戲並建立桌面及開始功能表捷徑。
- DMM Game Player 未登入時會自動在瀏覽器開啟登入頁。
- 可自選要出現在啟動清單中的 DMM 遊戲。
- 系統語系不是日文的電腦上，DMM 遊戲也會以日文字碼頁啟動。

### 變更

- DMM Game Player 在背景執行，只有按下顯示才會到前景。
- patch 會自行找到對應的遊戲。
- 流量動畫變矮，側邊按鈕與之對齊。
- DMM 模式不需清單即自動讓 DMM Game Player 的網站走 VPN。
