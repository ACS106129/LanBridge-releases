# Beta 變更記錄

LanBridge Beta 版的變更記錄在這裡；正式版請見 [CHANGELOG.zh-Hant.md](../CHANGELOG.zh-Hant.md)。

## [1.1.0-beta.1] - 2026-09-30

### 新增

- 已安裝的 DMM 遊戲可一鍵啟動。
- 連線後自動載入 DMM 帳號中的遊戲。
- 可安裝 DMM 遊戲並建立桌面及開始功能表捷徑。
- DMM Game Player 未登入時會自動在瀏覽器開啟登入頁。
- 可自選要出現在啟動清單中的 DMM 遊戲。
- 系統語系不是日文的電腦上，DMM 遊戲也會以日文字碼頁啟動。

### 變更

- DMM Game Player 在背景執行，只有按下顯示才會到前景。
- patch 會自行找到對應的遊戲。
- 流量動畫變矮，側邊按鈕與之對齊。
- DMM 模式不需清單即自動讓 DMM Game Player 的網站走 VPN。
