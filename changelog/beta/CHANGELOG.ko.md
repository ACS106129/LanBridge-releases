# 베타 변경 기록

LanBridge 베타 버전의 변경 사항을 여기에 기록합니다. 정식 버전은 [CHANGELOG.ko.md](../CHANGELOG.ko.md)에 있습니다.

## [1.1.0-beta.6] - 2026-10-02

### 수정

- 연결 후 몇 시간이 지나도 DMM 지역 확인을 통과합니다.

## [1.1.0-beta.5] - 2026-10-01

### 수정

- 게임을 시작할 때 DMM Game Player가 전혀 나타나지 않습니다.

## [1.1.0-beta.4] - 2026-10-01

### 수정

- 새 버전을 최대 1시간 기다리지 않고 몇 분 안에 찾습니다.

## [1.1.0-beta.3] - 2026-10-01

### 수정

- '지금 업데이트'는 창을 바로 열고 업데이트 내용은 창 안에서 불러옵니다.
- 게임을 시작할 때 DMM Game Player가 잠깐 나타나지 않습니다.
- DMM Game Player가 시작하지 않은 프로그램은 더 이상 대상이 아닙니다.

## [1.1.0-beta.2] - 2026-10-01

### 변경

- 베타를 켜거나 끄면 업데이트 안내만 띄우고 설치는 직접 정합니다.
- 베타 업데이트 내용이 사용자 언어로 모든 버전과 함께 표시됩니다.
- 설정과 사이트 목록에서 불필요한 설명을 뺐습니다.
- 모든 트래픽을 VPN으로 보낼 때는 사이트 목록을 숨깁니다.
- DMM Game Player가 실행 중이 아니면 표시 버튼을 누를 수 없습니다.
- 패치가 게임 파일을 바꾸지 않아 다시 다운로드되지 않습니다.

### 수정

- DMM Game Player가 먼저 파일을 받아야 할 때도 게임이 시작됩니다.
- 업데이트 내용의 제목이 제대로 표시됩니다.

## [1.1.0-beta.1] - 2026-09-30

### 추가

- 설치된 DMM 게임을 한 번의 클릭으로 실행합니다.
- 연결되면 DMM 계정의 게임을 자동으로 불러옵니다.
- DMM 게임을 바탕 화면과 시작 메뉴 바로 가기와 함께 설치할 수 있습니다.
- DMM Game Player 로그아웃 시 브라우저에서 로그인 페이지를 엽니다.
- 실행 목록에 표시할 DMM 게임을 고를 수 있습니다.
- 일본어 로캘이 아닌 PC에서도 DMM 게임을 일본어 코드 페이지로 실행합니다.

### 변경

- DMM Game Player는 백그라운드에서 실행되고 표시할 때만 나타납니다.
- 패치가 자신의 게임을 직접 찾습니다.
- 트래픽 애니메이션이 낮아지고 옆 버튼도 이에 맞춰졌습니다.
- DMM 모드는 목록 없이 DMM 사이트를 VPN으로 보냅니다.
