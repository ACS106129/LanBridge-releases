# 베타 변경 기록

LanBridge 베타 버전의 변경 사항을 여기에 기록합니다. 정식 버전은 [CHANGELOG.ko.md](../CHANGELOG.ko.md)에 있습니다.

## [1.1.0-beta.1] - 2026-09-30

### 추가

- 설치된 DMM 게임을 한 번의 클릭으로 실행합니다.
- 연결되면 DMM 계정의 게임을 자동으로 불러옵니다.
- DMM 게임을 바탕 화면과 시작 메뉴 바로 가기와 함께 설치할 수 있습니다.
- DMM Game Player 로그아웃 시 브라우저에서 로그인 페이지를 엽니다.
- 실행 목록에 표시할 DMM 게임을 고를 수 있습니다.
- 일본어 로캘이 아닌 PC에서도 DMM 게임을 일본어 코드 페이지로 실행합니다.

### 변경

- DMM Game Player는 백그라운드에서 실행되고 표시할 때만 나타납니다.
- 패치가 자신의 게임을 직접 찾습니다.
- 트래픽 애니메이션이 낮아지고 옆 버튼도 이에 맞춰졌습니다.
- DMM 모드는 목록 없이 DMM 사이트를 VPN으로 보냅니다.
