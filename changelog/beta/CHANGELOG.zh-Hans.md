# Beta 变更记录

LanBridge Beta 版的变更记录在这里；正式版请见 [CHANGELOG.zh-Hans.md](../CHANGELOG.zh-Hans.md)。

## [1.1.0-beta.1] - 2026-09-30

### 新增

- 已安装的 DMM 游戏可一键启动。
- 连接后自动加载 DMM 账号中的游戏。
- 可安装 DMM 游戏并创建桌面及开始菜单快捷方式。
- DMM Game Player 未登录时会自动在浏览器打开登录页。
- 可自选要出现在启动列表中的 DMM 游戏。
- 系统区域不是日文的电脑上，DMM 游戏也会以日文代码页启动。

### 变更

- DMM Game Player 在后台运行，只有按下显示才会到前台。
- patch 会自行找到对应的游戏。
- 流量动画变矮，侧边按钮与之对齐。
- DMM 模式无需列表即自动让 DMM Game Player 的网站走 VPN。
