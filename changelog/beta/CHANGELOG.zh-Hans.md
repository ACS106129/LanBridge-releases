# Beta 变更记录

LanBridge Beta 版的变更记录在这里；正式版请见 [CHANGELOG.zh-Hans.md](../CHANGELOG.zh-Hans.md)。

## [1.1.0-beta.5] - 2026-10-01

### 修正

- 启动游戏时 DMM Game Player 完全不会出现，不再闪一下。

## [1.1.0-beta.4] - 2026-10-01

### 修正

- 新版本会在几分钟内检测到，不必再等最多一小时。

## [1.1.0-beta.3] - 2026-10-01

### 修正

- “立即更新”会立刻打开窗口，更新说明在窗口内加载。
- 启动游戏时，DMM Game Player 不会再闪现在屏幕上。
- 不是 DMM Game Player 启动的程序，不再被当作连接的一部分。

## [1.1.0-beta.2] - 2026-10-01

### 变更

- 开启或关闭 Beta 只会提示更新，由你决定是否安装。
- Beta 更新说明以你的语言显示，并列出这次更新包含的每个版本。
- 设置与网站列表移除多余的说明文字。
- 所有流量送进 VPN 时隐藏网站列表。
- 没有运行 DMM Game Player 时，显示按钮无法使用。
- 补丁不再修改游戏文件，DMM Game Player 不会再重新下载它们。

### 修正

- DMM Game Player 需要先下载文件时，DMM 游戏也能正常启动。
- 更新说明中的标题正确显示。

## [1.1.0-beta.1] - 2026-09-30

### 新增

- 已安装的 DMM 游戏可一键启动。
- 连接后自动加载 DMM 账号中的游戏。
- 可安装 DMM 游戏并创建桌面及开始菜单快捷方式。
- DMM Game Player 未登录时会自动在浏览器打开登录页。
- 可自选要出现在启动列表中的 DMM 游戏。
- 系统区域不是日文的电脑上，DMM 游戏也会以日文代码页启动。

### 变更

- DMM Game Player 在后台运行，只有按下显示才会到前台。
- patch 会自行找到对应的游戏。
- 流量动画变矮，侧边按钮与之对齐。
- DMM 模式无需列表即自动让 DMM Game Player 的网站走 VPN。
