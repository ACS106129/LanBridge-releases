# 變更記錄

本檔案記錄 LanBridge 的所有重要變更。

格式依循 [Keep a Changelog](https://keepachangelog.com/zh-TW/1.1.0/)，版本號依循
[語意化版本](https://semver.org/lang/zh-TW/)。

## [0.5.3] - 2026-09-12

### 修正

- **其中一台開的房間，另一台看得到卻加不進去。** 入站只放行了探索用的連接埠，而那不一定是房主
  實際監聽的那一個：Warcraft III 拿得到 6112 就用 6112，拿不到就往上找到 6119，並把實際拿到的
  那個寫進房間資訊。於是被擠離 6112 的房主看得到卻連不上——而且只有那一個方向，所以看起來像是
  其中一台機器有問題。現在整段開房用的範圍都會放行，一樣只對 VPN 網段。
- **房主離開房間後，對方的清單裡還留著那個房間。** Warcraft III 是用廣播宣告房間關閉的，而廣播
  可能從 VPN 網卡送出去——中繼刻意不在那裡監聽，所以這個宣告從來沒有被收到，對方就一直顯示一個
  已經不存在的房間。現在中繼會察覺房主不再回應探測，並用它最後轉送出去的房間資訊指明是哪一間，
  自己送出撤銷通知。
- **切換語言會讓「目標程式」和「區網探索」的下拉選單變成空白**，而選擇「跟隨系統」則會讓語言
  下拉選單本身變成空白。重新翻譯一份清單等於把裡面的項目換掉，而下拉選單會把「被選中的那一項
  被換掉」視為那一項不見了——於是清除選取，綁定再把這個空值寫回原本的選擇上。現在項目本身不會
  被換掉，只換它的文字，也就沒有東西可以被清除。前兩次的修正是事後把選取補回來，這一次是拿掉
  成因。
- **在設定視窗裡切換語言時，視窗本身的標題和按鈕仍然是舊語言。** 視窗內容裡的文字都會重新標示，
  但標題和關閉按鈕不屬於那些內容，因此被漏掉。
- **訊息記錄不會穩定地跟著新的一行。** 捲動發生在新的一行完成排版之前，所以捲到的是「原本的
  底部」，永遠慢一行。現在改在排版之後才捲動，而且只要你往上捲去看東西就會停止跟隨，捲回底部
  後恢復。
- **升級時不論檔案有沒有變動都會整包重寫。** 舊版會在新版寫入任何一個檔案之前就被整個移除，
  所以每次升級都要重寫整個安裝內容。現在改成先寫入新版、之後才移除舊版，安裝程式就能跳過內容
  完全相同的檔案，只留下真正有變動的部分要寫。
- **訊息面板其中一顆按鈕有配置、可點擊，卻從來沒有被畫出來。**「開啟記錄資料夾」佔著它的位置、
  按下去也有反應，但畫面上什麼都看不到。現在這幾顆按鈕改為單一橫向排列，而不是各佔一欄，拿掉了
  出問題的逐欄配置。

### 新增

- **設定旁邊多了一顆程式資訊按鈕**：顯示目前執行的是哪一個版本、著作權，以及該版本說明與下載的
  連結。
- **安裝程式最後一頁新增「啟動 LanBridge」勾選項**，預設勾選。它會以非提權的方式啟動程式，
  也就是 LanBridge 原本該有的執行方式——權限是在連線開始時才請求，而不是事先取得。

### 變更

- **關閉目標程式現在只有在隧道綁定它時才會結束連線。** 勾選「只讓這個程式能使用 VPN」時，隧道
  是為那一個程序而存在的，所以隨它一起結束——否則留下的會是一條這台機器上沒有任何程式被允許使用
  的隧道。沒有勾選時，隧道只是依目的地限制範圍，可能還在為其他東西傳送流量，因此會保持連線直到
  你按下停止。

## [0.5.2] - 2026-09-11

### 修正

- **更新視窗裡的更新內容只顯示第一行標題。** 更新內容從變更記錄取出時會統一成單純的換行字元，
  而 Windows 的文字控制項是以歸位字元斷行——於是第一行之後的內容完全沒有被畫出來。英文的發行
  說明本身就帶著歸位字元，所以只有翻譯過的內容看起來是空的。現在會在顯示前先轉換，並改以可
  捲動、可選取的區塊呈現。

## [0.5.1] - 2026-09-11

### 修正

- **房間看得到卻加不進去，或是根本看不到。** 讓一個房間可以被加入的東西，全部都是從隧道
  **進來**的方向，而 Windows 預設把它們全部擋掉：隊友中繼過來的房間資訊是入站 UDP，加入房間
  則是一條入站 TCP 連線。命令列版本會把兩者放行，App 從來沒有移植這一段，於是哪一台沒有留下
  命令列版建立的規則，那一台就會在其中一個或兩個方向上連不通。現在一次連線只會針對 VPN 網段
  放行探索連接埠——而不是對這台機器所在的每一個網路——並把 Windows 預設歸類為「公用」的隧道
  網卡改為私人，兩者都在連線結束時還原。
- **文字大小只要調得比預設大，版面就跑掉，而且重新啟動也救不回來。** 縮放的圖層先被置中，
  再從它自己的左上角放大，於是整個介面從偏下偏右的位置開始，右側和底部被裁到畫面外——設定
  按鈕也一起被裁掉。由於文字大小會被記住，每次重新啟動都回到同樣的壞掉狀態，而且沒有任何
  途徑回去改那個造成問題的設定。
- **下載更新時完全沒有進度顯示。** 一按下「下載」視窗就關閉，傳輸在畫面上毫無動靜的情況下
  進行，和根本沒開始下載看起來一模一樣。現在更新內容的視窗會留著，顯示進度列、已傳輸的大小，
  以及一個真的有作用的「取消」。
- **自動檢查更新重新開啟後，最多四小時內不會有任何作用。** 背景檢查只在下一次排定的時間才
  重新看這個設定；現在會立刻去查。
- **在同一次進入設定時切換語言，關閉視窗的選擇看起來像是被丟掉了。** 翻譯清單會換掉被選取的
  那一項，選取狀態因而被清除——其他下拉選單會自己補回來，這一個沒有。

### 新增

- **縮到通知區域時也會檢查更新**，每四小時一次，而不再只有啟動時檢查。找到新版本會以通知區域
  的氣泡提示，氣泡消失後圖示的提示文字仍然會繼續標示。
- **設定裡新增「立即檢查」按鈕**，不必等下一次排定的檢查。

## [0.5.0] - 2026-09-11

### 修正

- **開啟遊戲房間的瞬間 VPN 就斷線。** 尋找啟動器交棒對象的邏輯只比對同名的執行檔，
  因此以不同名稱繼續執行的遊戲永遠找不到，隧道就被拆掉了。現在只要仍在同一個
  安裝資料夾內執行的行程都算，而且搜尋過程會顯示它找了什麼。
- **session 結束後按停止沒有任何作用。** 關閉與協助程式之間的管線時，
  對端已消失會拋出例外，而該例外逸出了清理流程 —— 程式因此一直以為
  已結束的 session 還在執行。
- **切換語言時所有下拉選單變成空白**，而不是切換成對應語言。更換清單內容會清除選取項目，
  繫結再把那個空白選取寫回去。
- **訊息記錄不會跟著新內容捲動。** 現在會自動捲到最新一筆，而當你往上捲動閱讀時
  就會停止自動跟隨。

### 新增

- **以你的語言顯示更新內容。** 翻譯後的變更記錄會與安裝檔一同發佈，
  更新對話框會顯示與介面語言相符的那一份。
- **匯出錯誤報告**：只要發生過失敗就會出現並帶有標記的按鈕。
  它會把畫面上的訊息與兩個行程的記錄檔打包在一起，
  讓你不必知道記錄檔放在哪也能回報問題。
- 文字大小設定現在會縮放整個介面，而不只是訊息區。

## [0.4.0] - 2026-09-10

### 新增

- **自動檢查更新。** 程式可查詢 GitHub 上是否有新版本，並在安裝前顯示更新內容。
  預設開啟，可在設定中關閉。
- **設定對話框**（齒輪按鈕），包含語言、介面文字大小、關閉行為與更新檢查 ——
  讓「記住我的選擇」之後仍有路可改。
- **新增十種介面語言**：簡體中文、日本語、한국어、Español、Français、Deutsch、
  Português、Русский、Italiano，加上原有的英文與繁體中文。狀態文字、下拉選項、
  對話框與通知區域選單全部翻譯。
- **訊息記錄改為可選取的文字**，並加上「複製全部」與「匯出…」按鈕。
- **介面文字大小可調**（10–22pt），並在下次開啟時記住。
- **應用程式圖示**，用於視窗、工作列、通知區域與「新增或移除程式」。
- **安裝程式會詢問安裝位置**，開始功能表捷徑與桌面捷徑也改為兩個獨立選項。

### 修正

- **遊戲載入完成的瞬間 VPN 就斷線。** 魔獸爭霸 III 和多數帶啟動器或更新程式的遊戲
  一樣，會結束第一個行程並交棒給另一個。程式原本把那次結束當成「目標已關閉」，
  於是在最不該的時機拆掉隧道。現在會追蹤程式在交棒後的實際行程。
- **通知區域圖示從未出現。** 圖示 handle 在 Windows 使用之前就被銷毀，
  而 `Shell_NotifyIcon` 拿到已失效的 handle 時不會顯示也不會報錯。
- **從通知區域重新開啟會變成第二份程式**，而不是還原正在執行的那一份。
  現在每位使用者只會有一個執行個體，再次啟動會把既有視窗帶到前景。
- **關閉程式後 `WinDivert64.sys` 仍被佔用。** 關閉驅動 handle 並不足夠 ——
  開啟時會註冊一個持續執行的核心服務，檔案會一直被鎖到服務停止為止。
  現在 session 結束時會停止並移除該服務。關閉視窗也會一併停止提權協助程式，
  這是先前沒做的。
- **語言切回「跟隨系統」時沒有任何反應。** 原本只送出一次「全部變更」通知，
  而 WinUI 不會據此可靠更新；現在每個字串都會具名通知。
- **解除安裝時要求重新啟動電腦。** 安裝程式現在會先關閉程式與其協助行程，
  不會留下使用中的檔案。
- 訊息記錄的每一列有清單項目的內距，行與行之間多出半行空白。

### 變更

- 記錄相關按鈕移到右側的訊息面板，不再夾在設定欄位的下方。

## [0.3.0] - 2026-09-09

### 新增

- 錯誤記錄寫入 `%LOCALAPPDATA%\LanBridge\logs\`，每個行程每次執行一個檔案；
  未處理的例外會在三個位置被攔截並記錄，而不是讓程式無聲結束。
- 設定持久化：每次變更即儲存，當機或被強制關閉也不會遺失。
- 通知區域支援，關閉時會詢問要結束還是縮小到通知區域。
- 繁體中文介面。
- MSI 安裝程式，含開始功能表與桌面捷徑、版本資訊與「新增或移除程式」項目。

### 修正

- 發佈版會啟動後隨即在 XAML 執行階段崩潰：未封裝的 WinUI 程式在發佈時
  不會帶上編譯後的標記語言，導致 `InitializeComponent` 無法載入。

## [0.2.0] - 2026-09-09

### 修正

- **通過提權提示後視窗從未出現。** WinUI 3 無法以提權方式執行 ——
  WinRT activation 會失敗，行程直接結束且不顯示任何東西。
  介面現在以一般權限執行，並把特權工作交給獨立的協助行程，
  每個 session 請求一次授權。介面本身不持有任何權限，
  協助行程也只在 session 執行期間持有。

## [0.1.0] - 2026-09-09

### 新增

- 單一程式的 VPN：匯入 OpenVPN 設定檔並拒絕伺服器推送的預設路由與 DNS，
  只有 VPN 網段會經過隧道，機器其餘部分維持原本的網路路徑。
- 選用的每行程隔離（使用 WinDivert），丟棄目標程式以外所有行程送往 VPN 網段的封包。
- 針對無法傳遞廣播的隧道的區網探索中繼，包含魔獸爭霸 III 的 W3GS 協定 ——
  它的房間資訊只以單播回覆傳送、從不廣播，因此必須主動向本機遊戲索取後再轉發。
- 適用其他遊戲的通用 UDP 廣播中繼，以連接埠設定。
- 同一套引擎的無介面命令列版本。
